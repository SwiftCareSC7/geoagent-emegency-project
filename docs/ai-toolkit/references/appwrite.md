Repository: <https://github.com/appwrite/appwrite>

## Purpose

End-to-end backend-as-a-service platform covering Auth, Databases, Storage, Functions, and Realtime messaging.

## Integration in SwiftCare

- SwiftCare utilizes a custom Express + MongoDB + Socket.IO + Leaflet stack. Appwrite serves as an architectural pattern reference for real-time WebSocket subscriptions and auth RBAC.
