# Build With Claude Reference
Repository: https://github.com/davepoon/buildwithclaude
License: MIT

## Purpose
A single hub to find Claude Skills, Agents, Commands, Hooks, Plugins, and Marketplace collections to extend Claude Code, Claude Desktop, Agent SDK, and OpenClaw.

## Integration in SwiftCare
- Claude commands and hook architecture in .claude/settings.json align with buildwithclaude standards.
- Custom prompts and slash-commands (/ponytail, /caveman, /goal) follow these community patterns.
