# SwiftCare GeoAgent — Subdirectory Note

> [!NOTE]
> The active, production **SwiftCare GeoAgent** application (Next.js 16 App Router, React 19, Tailwind CSS v4, Driver Dashboard) is hosted at the **repository root**:
> - `/app`: App router pages (`/`, `/login`, `/signup`, `/driver/dashboard`)
> - `/components`: UI widgets & dashboard components
> - `/lib`: API client and mock data
> - `/server`: Node.js + Express + MongoDB backend
> - `/routing-engine`: Python spatial routing & V2X engine
>
> To run the main frontend application:
> ```bash
> cd ..
> npm install
> npm run dev
> ```
>
> Visit [http://localhost:3000](http://localhost:3000) for the main application.
