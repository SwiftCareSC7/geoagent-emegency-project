# SwiftCare Fullstack Design Loop Skill

## Core Principles
1. NEVER LOSE EXISTING FUNCTIONALITY.
   - Maintain a complete functionality preservation matrix.
   - Inspect every route, page, component, button, form, tab, dropdown, modal, drawer, map control, filter, API, backend service, database model, Socket.IO event, GeoAgent flow, Decision Engine flow, auth flow, role restriction, driver/paramedic/admin/lab workflows.
2. DO NOT STOP EARLY.
   - Stop only when all quality gates (Phases 53–62) pass.
3. PRESERVE HUMAN-IN-THE-LOOP & OPERATIONAL CALM.
   - Clear epistemic states: OBSERVED, INFERRED, UNKNOWN.
   - GeoAgent is an operational reasoning layer (not a consumer chatbot).
   - High information hierarchy, calm dark/light palette, high trust.
4. MAP & ROUTE TRUTH.
   - Real geometry, correct coordinate ordering ([lng, lat] GeoJSON vs [lat, lng] Leaflet).
   - Planned route (blue), Recommended alternative (purple), Other alternatives (gray), Actual GPS trajectory (orange), Incidents (red).
5. MASTER LOOP:
   - INSPECT -> AUDIT -> RESEARCH -> DESIGN -> IMPLEMENT -> BROWSER TEST -> VISUAL/FUNCTIONAL/A11Y/PERF QA -> REGRESSION -> COMPLETE.
